# go-algo

A collection of common algorithms and data structures implemented in Go, designed to be reused across multiple projects.

## Installation

```bash
go get github.com/jjmrocha/go-algo
```

## Usage

Import the specific package you need in your Go code:

```go
import "github.com/jjmrocha/go-algo/sorting"
```

## Project Structure

The library is organized into different packages based on algorithm categories:

- `sorting/` - Sorting algorithms
- `searching/` - Searching algorithms
- `datastructures/` - Common data structures
